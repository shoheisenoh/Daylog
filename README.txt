DAYLOG — Soft Motion Edition

内容
- index.html: アプリ本体
- manifest.webmanifest: PWA設定
- service-worker.js: オフライン用キャッシュ
- icon.svg / icon-192.png / icon-512.png: アプリアイコン

使い方
1. フォルダ内のファイル一式をHTTPS対応のWebサーバーへ配置します。
2. index.htmlを開くと利用できます。PWAとしてインストールする場合はHTTPS環境で開いてください。
3. タイマー下の「設定」を開くと、ラベル名・色、テーマ、JSONバックアップを管理できます。

データ
記録は利用中のブラウザ内（localStorage）に保存されます。端末間の移行には「JSONを書き出す」「JSONを読み込む」を使ってください。
タイマーは開始・一時停止の時刻を保存し、再表示時に経過時間を再計算します。ブラウザを閉じている間にバックグラウンド処理を行う方式ではありません。

表示
日別の記録は、24時間の時間帯グラフとカテゴリ別内訳で確認できます。日付の前後移動とカレンダー選択に対応し、未来の日付は選択できません。

タイマー数字は桁位置を固定し、小数点以下の10分の1の位だけを控えめにフェードします。上下移動・バウンスはありません。端末の「視差効果を減らす」設定にも対応します。

ラベル選択
- タイマー横のラベルボタンを押すと、色見本・ラベル名・選択チェック付きのカスタムメニューが開きます。
- タップ／クリックで選択できます。キーボードでは上下矢印、Home、End、Enter、Escapeに対応します。
