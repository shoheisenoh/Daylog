DAYLOG v83

今回の更新:
- 共通の読み込み画面と進捗表示を追加（ライト／ダークテーマ対応）。
- 分析集計は記録・日付のまとまりごとに処理を区切り、完了数に応じて進捗を更新。
- JSON読み込みはファイル読込・解析・検証・保存の段階を表示。大きなJSONはWorker内で読み込み、読み込み済みバイト数を進捗に反映。
- JSON書き出しはバックアップ準備・JSON生成・ダウンロード準備の段階を表示。対応ブラウザーではJSON生成をWorkerへ移譲。
- 別端末との合成は重複照合・ラベル対応付け・既存記録の保持を分割して進捗表示。
- 動きを減らす設定ではローディングアニメーションも抑制。
- 保存形式 v6 と保存キー daylog.data.v3 は変更なし。

インストール:
1. ZIPを展開
2. DAYLOGフォルダーをWebサーバー等に配置
3. 既存PWAは更新後に再読み込み
