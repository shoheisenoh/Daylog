# DAYLOG v102 — 日課追加フォームの視認性調整

## 変更内容

- 日課追加用のテキストボックスを、旧オプション欄と同じ明るい `surface` 背景に変更し、フォーム内で見分けやすく調整。
- オプション欄は `bg` 背景と控えめな境界線に変更。見出し・開閉記号・補足表示もミュート色に寄せて主張を抑制。
- 入力欄の文字色、プレースホルダー、入力動作、保存処理は維持。フォーカスリングは既存のアクセント色を維持。
- ダークテーマでもテーマ変数に追従し、追加タスクの種類、周期設定、カスタムselectの動作には変更なし。

## 互換性

データ形式v6、保存キー `daylog.data.v3` を維持。日課データ・既存のJSONバックアップ形式は変更なし。

## PWA

Service Workerキャッシュ名: `daylog-routine-contrast-v102`。v101キャッシュを既知の旧キャッシュとして削除対象に追加。HTML単体版とPWAの `index.html` はバイト一致。


## DAYLOG v103 — 日課オプションの階層デザイン

- 日課追加フォームの「オプション」を、同じ設定画面の「ラベル ＞ サブラベル」と同じ入れ子レベルの配色・境界線・開閉矢印に統一。
- 展開時の内容は内側に収め、入力コントロールはサブラベル入力欄と同じ `surface` 背景に変更。
- 日課名入力欄、タスク種類、周期設定、カスタムselect、保存形式は変更なし。
- ライト／ダークテーマともテーマ変数に追従。
- PWAキャッシュ名: `daylog-routine-sublabel-style-v103`。


## DAYLOG v104 — オプション見出しサイズ調整

- 日課追加フォームの「オプション」見出しの高さ・左右余白・文字色・文字サイズ・太さを、ラベルの「自動終了・サブラベル」折りたたみ見出しに合わせて37pxに統一。
- 原因だった `.settings summary` の共通指定（52px）が日課オプション見出しに残るカスケードを、日課オプション専用の後段ルールで解消。
- ラベル側やその他の設定見出し、入力欄、開閉・選択・保存ロジックは変更なし。
- データ形式v6、保存キー `daylog.data.v3` を維持。
- PWAキャッシュ名: `daylog-routine-options-size-v104`。v103を既知の旧キャッシュとして削除対象に追加。


## DAYLOG v107 — 循環式・慣性強化タイムホイール

- リセット時刻は通常時に現在値だけを表示し、時刻ボタンをタップするとホイールパネルを開閉する設計に変更。Escキーでも閉じられる。
- 時・分それぞれの選択肢を複数周ぶん連結し、端に達すると同じ値の中央周へ位置を補正する循環式ホイールに変更。
- タッチ／マウスドラッグ時の慣性を強め、停止時は強めのイージングで最寄りの行に吸着。トラックパッド／マウスホイール、キーボード操作も継続対応。
- 既存の日課リセット処理、保存形式v6、保存キー `daylog.data.v3` は維持。
- PWAキャッシュ名: `daylog-routine-wheel-loop-v107`。v106を既知の旧キャッシュとして削除対象に追加。


## DAYLOG v108 — ダークモードの日課追加ボタン・自然な慣性スクロール

- ダークテーマの日課「追加」ボタンを、明るい単色アクセントから落ち着いたクレイ系の面色へ調整。暖色の文字色と境界を保ち、ダーク画面で浮きすぎない配色に変更。ライトテーマは従来どおり。
- 時刻ホイールのフリック慣性を拡張。初速を高め、減速率を緩やかにして、短いフリックでも複数周を回転した後に自然減速する動作へ変更。
- 自由回転のあとには、選択行へ軽く吸着するスナップを維持。ループ補正、時刻保存、データ形式v6は維持。
- PWAキャッシュ名: `daylog-routine-apple-scroll-v108`。v107を既知の旧キャッシュとして追加。


## DAYLOG v109 — フリック速度連動・弱めの吸着

- 時刻ホイールの指移動サンプルから直近の速度を推定し、pointerup位置も速度計算に反映。素早いフリックは離した後の初速へ強く引き継ぎ、短時間の惰性回転を維持。
- 指を離す前に手を止めた場合は速度が自然に減衰するよう、直近のサンプルを加重して推定。
- 慣性の初速係数を5.0、上限14px/ms、フレーム保持率0.9885、最大惰性時間9秒へ調整。
- 停止時の行吸着は強い5乗イージングから穏やかな3乗イージングへ変更し、所要時間も短縮。最終的には行に整列するため時刻値の読み違いは防止。
- データ形式v6、保存キーdaylog.data.v3、循環補正、時刻の自動保存は維持。
- PWAキャッシュ名: `daylog-routine-touch-speed-v109`。v108を既知の旧キャッシュとして追加。


## DAYLOG v110 — 日課メーターの描画安定化

- 周期タスクのストックメーターを、通常ストック／予備ストックの複数塗りつぶし要素から、単一の塗りつぶし要素＋CSSグラデーションへ変更。描画順や隣接レイヤーの幅解釈に依存せず、色の切れ目・未描画領域が出にくい構造に整理。
- ストック数・最大値・各幅を0〜上限の範囲に正規化し、不正値や端数による負幅・100%超過を防止。0ストックは空、通常目標以下はアクセント色、目標超過分は予備色で表示。
- 毎日タスクの折りたたみ／展開メーターも表示ブロック化し、色のフォールバックと達成率の0〜100%クランプを追加。
- 日課のストック計算・記録処理、リセット境界、保存形式v6、保存キー `daylog.data.v3` は変更なし。
- PWAキャッシュ名: `daylog-routine-meter-fix-v110`。v109キャッシュを既知の旧キャッシュとして削除対象に追加。
