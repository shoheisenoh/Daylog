DAYLOG — Soft Motion Edition

内容
- index.html: アプリ本体
- manifest.webmanifest: PWA設定
- service-worker.js: オフライン用キャッシュ
- icon.svg / icon-192.png / icon-512.png: アプリアイコン

使い方
1. フォルダ内のファイル一式をHTTPS対応のWebサーバーへ配置します。
2. index.htmlを開くと利用できます。PWAとしてインストールする場合はHTTPS環境で開いてください。
3. タイマー下の「今回の自動終了」で、その回だけ終了方法を変更できます。「設定」ではラベル名・色・並び順・サブラベル・ラベルごとの自動終了デフォルト・テーマを管理できます。

データ保存・バックアップ
- 計測記録、開始・終了時刻、時間区間、一時停止状態、自動終了情報、終了時刻の確認状態を保存します。
- ラベル名・色・並び順、サブラベル名・並び順、ラベルごとの自動終了デフォルト、表示テーマ、選択中のラベル・サブラベル、「今回だけ変更」の自動終了方法・時間、タイマー背景アニメーションのON/OFF・強さ・ラベルカラー連動も保存します。
- 端末内の保存形式はv5です。以前のv3・v4データは起動時に自動移行します。
- JSONの書き出しは、記録とすべてのカスタム設定を含むバックアップを作成します。JSONの読み込みは、ファイル形式・ID重複・時間区間・計測状態などを検査してから反映します。不正なファイルや保存失敗の場合は、現在のデータを置き換えません。
- データは利用中のブラウザ内（localStorage）に保存されます。端末間の移行には「JSONを書き出す」「JSONを読み込む」を使ってください。定期的なバックアップをおすすめします。

タイマー・自動終了
タイマーは開始・一時停止の時刻を保存し、再表示時に経過時間を再計算します。自動終了は「指定した時間後」または「指定時刻」に設定できます。「指定した時間後」は一時停止中にカウントを止め、「指定時刻」は一時停止中でも終了します。ブラウザ／アプリを閉じている間は処理を実行できませんが、次回起動時に保存済みの終了予定時刻で記録を確定します。終了時刻は次回起動時に修正できます。

表示・ラベル
- 日別の記録は、24時間の時間帯グラフとカテゴリ別内訳で確認できます。下部のカレンダーから日付を選択できます。
- サブラベル付きラベルをタイマーで選ぶと、サブラベル一覧が親ラベルの右側に展開されます。「サブラベルなし」も選べます。
- 各ラベルの設定は「自動終了・サブラベル」の折りたたみにまとめています。
- ラベルの順番は、設定画面の上下ボタンで変更できます。ドラッグや長押しは不要です。
- サブラベルは日別内訳・時間帯グラフ・セッション履歴に親ラベル名と合わせて表示されます。

アニメーション
全体に控えめなフェード・展開・押下アニメーションを使用します。タイマー背景は「木漏れ日のゆらぎ・奥行きのある枝葉・雲による明暗変化」を組み合わせています。大小の木漏れ日模様が別々に移動し、手前・中間・奥の枝葉が異なる周期で揺れ、雲が通るように背景の明るさがゆっくり変化します。水面に浮かぶ葉っぱは表示しません。背景アニメーションのON/OFF・動きの強さ・ラベルカラー連動を設定でき、ON時はOSの視覚効果制限による自動抑制を行いません。OFF時はアプリ内のスイッチで全背景アニメーションを停止します。

更新内容（v45）：木漏れ日の模様を複数に増やし、枝葉を奥・中間・手前の4層に整理。雲が通るような明暗変化を追加。アニメーションのON/OFF・強さ・ラベルカラー連動を設定可能にし、JSONバックアップと端末内保存へ追加。保存形式v5へ更新し、旧v3・v4データとの互換性を維持。
