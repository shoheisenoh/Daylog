TEST ENVIRONMENT / LIMITATIONS
- Chromium 144.0.7559.96, headless, Playwright.
- Application was loaded with set_content in an isolated browser document and a simulated localStorage implementation. Blob Workers were available and tested. This is not equivalent to installing the PWA from a production HTTPS origin.
- Real service-worker installation, offline navigation, Safari/iOS, Firefox/WebKit and physical Android/iOS devices were not tested.
- No mandatory runtime-code changes were identified by these checks. The v83 application code is retained unchanged; this release updates only the accompanying audit / compatibility notes.
