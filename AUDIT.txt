DAYLOG v95 audit

Color audit findings and fixes:
1. v94 had an eight-entry dark display map with a sage fallback for every unlisted HEX color.
2. v94 safeColor() snapped valid non-preset HEX values to the nearest of eight presets, destroying custom hue distinctions.
3. v95 preserves every valid six-digit HEX color as lowercase canonical data; invalid values alone use the safe sage default.
4. v95 keeps all eight existing presets and adds four distinct purple/blue-purple presets (lilac, violet, plum, indigo).
5. v95 maps the original eight presets to their established dark variants; every other valid HEX value is converted by a hue-preserving RGB blend toward a neutral dark base. The blend reduces luminance for non-black colors while preserving hue within integer-rounding tolerance; pure black remains black.
6. The label editor exposes a custom/imported color as a "current color" swatch when it is not one of the presets.
7. Every label-color presentation path continues to use displayLabelColor(): label palette, timer tint/dots, label picker, overview, calendar, records, hourly breakdown, selected analysis choices, multi-series, legends, and charts.
8. Data format v6 and storage key daylog.data.v3 remain unchanged. Color conversion is presentation-only; saved color strings and exported colors are not rewritten by theme changes.

DAYLOG v109 time-wheel motion audit:
1. Replaced the short interval-average fling estimate with a recency-weighted velocity estimate over the last 100ms, with a bounded minimum interval for coalesced pointer events.
2. Pointer-up position is included where it differs from the last pointer-move; pauses before release bleed away momentum and a pause beyond 115ms cancels the fling.
3. Fling launch velocity is scaled by 5.0 and capped at 14 CSS px/ms. Retention is 0.9885 per 16.67ms frame, with a 9s safety maximum.
4. Reduced the post-coast alignment from quintic to cubic easing and shortened its duration. It remains aligned to a 36px row to keep the selected time unambiguous.
5. Circular normalization shifts the active gesture samples into the new coordinate space so a seam crossing does not discard fling velocity. Daily reset scheduling, save format v6, and storage key daylog.data.v3 are unchanged.
