DAYLOG v83 — Compatibility and Stability
Verification date: 2026-11-26

DATA AND STORAGE
- DATA_VERSION: 6 (unchanged)
- STORAGE_KEY: daylog.data.v3 (unchanged)
- v5 and v6 backup files were tested. A v5 backup imports and normalizes to v6.
- Labels, sessions, routines, check history, settings, analysis preferences and merge semantics retain their existing data shape and behavior.
- No destructive migration or session rewrite is introduced.
- Imports remain limited to 25 MiB. localStorage capacity varies by browser and device; quota errors are handled without replacing the saved snapshot.

JSON / WORKER COMPATIBILITY
- Files larger than 768 KiB use a short-lived Blob Worker for FileReader input progress and JSON parsing when Worker, Blob and object URLs are available.
- If Worker creation or execution is unavailable, import falls back to File.text() and main-thread JSON.parse(). This fallback was tested with Worker disabled.
- JSON output uses a short-lived Blob Worker for serialization when available, with JSON.stringify() fallback. Both paths were tested.
- Worker is an optimization, not a requirement for JSON import/export.

ANALYSIS / MERGE
- Analysis aggregation yields between session and day batches; progress tracks completed work. A fixture with 18,000 sessions completed and closed the loading overlay correctly.
- Cross-device merge yields during duplicate checks, label mapping and local-session copying. Unique imports, duplicate imports and conflicting duplicate IDs were tested.
- Import and merge save the fully validated candidate before replacing in-memory state.

PWA REQUIREMENTS
- The PWA uses a service worker and therefore must be hosted in a secure context (HTTPS; localhost is generally treated as secure by browsers).
- Opening the standalone HTML via file:// does not install or exercise the PWA service worker.
- The manifest, app-shell file references and icon assets were statically validated. Runtime service-worker installation and offline navigation were not exercised in this environment.

BROWSER COVERAGE
- Automated UI/logic checks: Chromium 144.0.7559.96 (headless), using Playwright. The page was loaded in an isolated browser document with a simulated localStorage implementation; this verifies application logic but is not a full HTTPS/PWA-origin test.
- Responsive layout was checked at 390 px viewport width; no horizontal overflow was observed.
- Safari/iOS, Firefox, WebKit and Android physical devices were not tested. Blob Worker fallback is provided for browsers that disallow or do not implement Workers.
