- Keeps v94 and earlier data format v6 and localStorage key daylog.data.v3.
- Preserves any valid #RRGGBB label/session color during normalization and JSON import; no nearest-preset coercion.
- Existing eight preset colors remain available; four purple-family presets are appended.
- Imported/custom colors not in the preset list remain visible in the editor as a current-color swatch.
- Light mode displays the original color. Dark mode changes only presentation and preserves hue for non-preset colors.
- Existing routines, cycle stock, streaks, label/settings layout, JSON import, and PWA behavior are retained.
- HTML standalone and PWA index.html are byte-identical.

Any color already overwritten by an older build cannot be inferred automatically; restore it by importing a backup that still contains its original HEX value.
